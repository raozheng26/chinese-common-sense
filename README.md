# 中国人常识补全地图

> 面向「中国教育背景 + 程序员」的功利性自我提升清单：不是成为其它领域的专家，而是用最小投入拿到最大的生活收益。学习强度由 **收益 × 性价比** 决定。

零依赖、单文件、可交互的 HTML 页面。评分针对特定人群画像（INTJ + 中国教育背景 + 程序员）主观校准，意在排序而非精确度量，供参考与按需调整。

## 功能

- **多维筛选**：类型 & 强度多选（空 = 全部）、收益 ≥ / 成本 ≤ / 性价比 ≥ 门槛、一键预设组合
- **排序 & 搜索**：表头点击排序（默认推荐分）、领域名 / 理由 / 资料 / 子领域的模糊搜索
- **展开详情**：每个领域附子领域 + B 站教程链接 + 实用中文资料
- **深浅色主题**：右上角切换，自动记忆偏好；移动端完整适配
- **零依赖**：单个 HTML 文件，浏览器直接打开即用

## 使用

- **在线**：直接访问上方链接
- **本地**：`git clone` 后用任意现代浏览器打开 `index.html`，无需构建、无需服务器

## 评分体系

每项按 1–5 打分：**收益**（到「够用」深度的人生价值）、**成本**（时间精力）、**频率**（一辈子实际用到频率）；推荐分 = (收益 + 收益/成本 + 频率×0.5) / 1.25。学习强度分 高（优先）/ 中（值得）/ 轻（浅尝按需，非跳过）。

> **两条纪律**（比清单本身更重要）：
> 1. 认死科普 + 天花板：尤其健康医学 / 法律 / 投资，「读三篇就敢上手」是 Dunning-Kruger 陷阱，价值在 *识伪 + 善用系统 + 知道何时交给专家*。
> 2. 区分知识 vs 技能：知识型领域科普即可；技能型领域不练没收益，要么真练要么当观众。
